## ⚙️ Run Locally

```bash
git clone https://github.com/sanketh908/Portfolio-v3.git
cd Portfolio-v3
```

Then open `index.html` in your browser, or serve the folder with a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
